# PC2 · Complejidad, búsqueda y ordenamiento

- **Semana:** 2
- **Fecha límite:** 25/10/2026 (entregada)
- **Modalidad:** grupal (Grupo 7)
- **Autora del código:** Nayda ([@qoriankaq20](https://github.com/qoriankaq20)). Repositorio original: [qoriankaq20/PC2-Algoritmos](https://github.com/qoriankaq20/PC2-Algoritmos)

## Contenido

| Archivo | Qué hace |
|---|---|
| `src/parte1_casos.py` | Análisis matemático de la complejidad en 10 casos (O(1), O(n), O(n²), O(log n)…) |
| `src/parte2_busquedas.py` | Búsqueda lineal, lineal acotada y binaria (iterativa y recursiva) |
| `src/parte3_ordenamiento.py` | Intercambio, burbuja, inserción, selección, rápido, montículo y mezcla |
| `src/parte4_experimentacion.py` | Experimentación y comparación de tiempos de búsqueda y ordenamiento |
| `informe/PC2-Semana2-informe.docx` | Informe entregado |
| `informe/PC2-Exposicion-busqueda-binaria.pptx` | Exposición de búsqueda binaria |

> En el repositorio original, la parte 4 no tenía la extensión `.py` (`parte4_experimentacion y comparacion de resultados`). Aquí se renombró para poder ejecutarla.

## Cómo ejecutar

```bash
python src/parte1_casos.py
python src/parte2_busquedas.py
python src/parte3_ordenamiento.py
python src/parte4_experimentacion.py --help
```
